# 無人水面載具（USV）

**Unmanned Surface Vehicle**

國立成功大學 水下技術研究中心（UTRC）／海洋科技工程實驗室（MATELab）

---

> **一句話定位**
> 一艘 2.8 公尺級、玻璃纖維雙體構型的智慧無人船，融合毫米波雷達、光達、聲納與慣性導航，以 ROS 結合深度強化學習（TD3）達成**路徑追蹤、動態避障、動態定位駐留與自動返航**；並具備**布放與回收水下載具（AUV）**的母船潛力，是本中心銜接水面與水下作業的關鍵平台。

---

## 一、能執行哪些任務

USV 以自主航行方式在水面執行任務，具備「自航模式」、「AI 分析」與「雲端監控」三層軟體能力：

| 任務模式 | 內容 | 應用價值 |
| --- | --- | --- |
| **路徑追蹤（Path Following）** | 依規劃航線精準航行，採 ALOS 導引法降低橫向偏差 | 海域測繪、航線巡查、定線作業 |
| **動態避障（Collision Avoidance）** | 多感測器融合即時偵測障礙，多層演算法維持安全距離 | 繁忙水域安全航行、自主任務保障 |
| **動態定位駐留（Station Keeping）** | GPS-INS 動態定位長時間穩定停留於指定位置 | 離岸維護、水下作業支援、定點觀測 |
| **自動返航（Return-to-Home）** | 任務結束或異常時自主返回起始點 | 無人化作業安全機制 |
| **直線航行 / 圓形循跡** | 於 HoloOcean 環境完成之基本操控驗證 | 控制演算法驗證與展示 |

上述任務已於 **ROS + Gazebo**（路徑追蹤、避碰駐留、自動返航）與 **ROS + 深度強化學習 + HoloOcean**（直線航行、圓形循跡）模擬環境完成驗證。

### 延伸應用場景
- **水下載具母船**：布放與回收 AUV／水下載具（本中心專利申請中之智能布放回收系統）
- 離岸風場、海洋工程結構之水面巡檢與支援
- 水文、水質與海域環境監測
- 港灣安全巡邏、搜救輔助
- 動態定位（DP）作業平台與離岸維護支援

## 二、感測器與酬載

| 類別 | 配置 |
| --- | --- |
| **視覺** | 雙目視覺 AI 相機、廣角雙鏡頭相機（IP67） |
| **測距 / 環境感知** | 廣角三維光達（Lidar）、毫米波雷達（77 GHz） |
| **水下感測** | 側掃聲納、聲納測深儀 |
| **導航定位** | INS／IMU 慣性導航、GNSS／GPS（高精度 RTK） |
| **熱影像** | 紅外線熱像儀 |
| **運算核心** | 中控電腦 NVIDIA Jetson、CANBUS 轉換器、感測器運算中心 |

多感測器融合（毫米波雷達＋光達＋側掃聲納）建構高精度環境模型，為避障與導航決策提供依據。

## 三、系統架構與控制

### 載具構型
- **船體**：玻璃纖維（FRP）雙體構型，上、中、下船殼模組化組裝
- **推進**：舷外機 ×2（各 20 HP）＋ 側推進器 ×2（各 2.04 HP），兼顧巡航速度與低速操控／定位
- **結構配件**：抽拉式機櫃、感測器平台／支架／塔架、聲納支架、防撞護舷、舷外機保護框
- **模組化設計**：高維護性與擴展性，支援多任務模組快速更換

### 電力與通訊
- **動力電池**：磷酸鐵鋰（LiFePO4）動力電池系統，48 V／額定容量約 600 Ah，含充電組、電源轉換器與電池遠端開關
- **通訊**：4G／5G／WiFi 多路備援
  - 五合一天線（Taoglas MA752，支援 LTE／Wi-Fi／GNSS／BT／Sub-1GHz）
  - LTE 模組（Quectel EC25）、Wi-Fi 模組（u-blox MAYA-W161）、高精度 GNSS RTK（u-blox F9P）

### 軟體與控制核心
- 以 **ROS** 為框架，Jetson 開發板為運算核心，透過 CANBUS 連結運動控制系統（舷外機）與側推控制模組（側推器）。
- **控制模型以 TD3 深度強化學習**實現智慧導航、動態避障與決策最佳化；路徑追蹤採智慧路徑追蹤節點（`/Intelligent Path Following_node`）結合 ALOS 導引。
- **三層軟體能力**：
  - 自航模式：定位保持、返航、航行圍籬（Geo-fencing）
  - AI 分析：物體辨識、防撞、路徑規劃（TD3）
  - 雲端服務：資料顯示、衛星圖資、船體監視、航程歷史紀錄
- 建立流體動力係數／模型並納入風、浪環境參數，於模擬環境重現載具運動，支援「先模擬、後海試」開發流程。
